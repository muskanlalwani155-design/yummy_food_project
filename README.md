# Yummy Food Project

A responsive, multi-page culinary and recipe website built purely with semantic **HTML5** and **CSS3**. It features dedicated pages for recipes, categories, food blogs, search, and contact details, enhanced with interactive hover states and modern styling.

* **Live Demo:** [https://muskanlalwani155-design.github.io/yummy_food_project/](https://muskanlalwani155-design.github.io/yummy_food_project/)
* **GitHub Repository:** [https://github.com/muskanlalwani155-design/yummy_food_project](https://github.com/muskanlalwani155-design/yummy_food_project)

---

## Features

* **Multi-Page Architecture:** Well-structured individual pages for Home, Categories, Recipes, Blog, Search, About Me, and Contact.
* **Pure CSS Interactivity:** Smooth UI transitions and hover effects styled without relying on external JavaScript libraries.
* **Responsive Layouts:** Structured using modern CSS Grid and Flexbox techniques for consistent presentation across screen sizes.
* **Semantic HTML:** Clean markup optimized for maintainability and web accessibility standards[cite: 3].

---

## Tech Stack

* **Markup:** HTML5 (28.8%)
* **Styling:** CSS3 (71.2% — Flexbox, CSS Grid, Hover Effects)
* **Hosting:** GitHub Pages
